# 两人食 · Table for Two

一个以米白与鼠尾草绿为主色的双人家庭点餐应用，使用 React 19、TypeScript 和 Vite 构建。

## 功能

- 添加、编辑、删除菜品，支持分类、烹饪时间和介绍；删除前二次确认。
- 分类筛选、名称和介绍搜索、收藏菜品。
- 在「我」与「TA」之间切换，分别选择菜品及份数。
- 今日餐桌汇总、修改份数、用餐备注、确认菜单与重新选餐。
- 浏览器 localStorage 保存菜单、点餐与备注，刷新后保留。
- 响应式桌面和手机布局，语义化表单、键盘焦点与原生对话框。
- 菜品插画为应用内 SVG，无外部图片或字体依赖。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

访问终端显示的地址（默认 `http://localhost:5173`）。

```sh
npm run build
npm run preview
```

构建产物在 `dist/`，可部署到任何静态托管服务。云容器需要端口转发后才能在本机访问。

## 数据范围

本项目是可独立运行的前端应用，没有后端和登录系统。双人模式在当前浏览器中切换；不同浏览器、设备之间不会自动同步。清除网站数据会移除本地保存的内容。浏览器存储不可用时页面会提示。
