# 两人食 · Table for Two

一个以米白与鼠尾草绿为主色的双人家庭点餐应用，使用 React 19、TypeScript 和 Vite 构建。

## 功能

- 添加、编辑、删除菜品，支持分类、烹饪时间和介绍；删除前二次确认。
- 分类筛选、名称和介绍搜索、收藏菜品。
- 在「我」与「TA」之间切换，分别选择菜品及份数。
- 今日餐桌汇总、修改份数、用餐备注、确认菜单与重新选餐。
- 浏览器 localStorage 保存菜单、点餐与备注，刷新后保留。
- 响应式桌面和手机布局，语义化表单、键盘焦点与原生对话框。
- 菜品插画为应用内 SVG，无外部图片或字体依赖。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm ci
npm run dev
```

访问终端显示的地址（默认 `http://localhost:5173`）。

```sh
npm run build
npm run preview
```

构建产物在 `dist/`，可部署到任何静态托管服务。云容器需要端口转发后才能在本机访问。

## 数据范围

本项目是可独立运行的前端应用，没有后端和登录系统。双人模式在当前浏览器中切换；不同浏览器、设备之间不会自动同步。清除网站数据会移除本地保存的内容。浏览器存储不可用时页面会提示。

网站现已设为公开，其他人拿到链接即可访问。页面提供「安装到手机」和「分享给朋友」。

- **iPhone / iPad**：在 Safari 打开应用网址，点分享按钮，选择「添加到主屏幕」；出现「作为网页 App 打开」时请开启。
- **安卓**：用 Chrome 或支持 PWA 的浏览器打开，点击页面「安装到手机」，或在浏览器菜单选择「安装应用／添加到主屏幕」。
- **微信内打开**：先在右上角菜单选择「在浏览器打开」，再安装。

安装形式为 PWA 网页应用，不需要应用商店账号或单独下载 APK / IPA。系统是否显示原生安装提示取决于浏览器支持。

首次联网打开，看到「离线已就绪」后，即可断网重新打开并操作菜单。若应用有新版本，会提示「更新并重新打开」；菜单保存在本机。不同浏览器、主屏幕应用与设备的存储空间可能独立，既有浏览器数据不保证迁移到安装后的应用。公开访问不等于共享数据库；目前每台设备独立使用。

生产构建自动执行 `scripts/generate-sw.mjs`，根据当次构建生成带版本号的离线缓存清单。开发模式不注册 Service Worker，验证 PWA 请执行 `npm run build && npm run preview`，然后通过 localhost 或 HTTPS 访问。
